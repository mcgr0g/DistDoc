# 0003 Open-Closed сериализация состояния

Status: accepted
Date: 2026-09-08

## Context and Problem Statement
Состояние схемы передаётся между воркерами Trino по сети (фазы Shuffle/Combine). Сетевой
сериализатор не должен меняться или перекомпилироваться при добавлении новых флагов
аномалий в dbt-детектор — иначе любое расширение детектора ломает сетевой контракт.

## Decision
Служебные метаданные (`type`, `max_length`) отделены от динамической карты аномалий.
При десериализации все неизвестные JSON-свойства интерпретируются как булевы флаги
аномалий и восстанавливаются в памяти рантайма.

## Consequences
- Open-closed сериализация: добавление флагов аномалий не требует правки сериализатора.
- Обратная совместимость по сети между воркерами разных версий плагина.
- Паттерн 4 из docs/patterns/plugin.md зафиксирован как архитектурное решение.
