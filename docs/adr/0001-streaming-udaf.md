# 0001 Streaming UDAF

Status: accepted
Date: 2026-09-08

## Context and Problem Statement
Интроспекция терабайтных таблиц выполняется в распределённом Trino: миллиарды строк,
полиморфный JSON с экранированными под-документами. Построение DOM-дерева на каждую
строку невозможно по памяти; нужен детерминированный обход без побочных эффектов от
глубокой вложенности.

## Decision
Интроспекция реализована как UDAF на однонаправленном стриминг-парсере (Streaming API);
DOM запрещён. Сложность O(N) по времени и O(1) памяти на строку. Пути JSONPath строятся
ручным стеком путей; при обнаружении вложенного экранированного JSON текущий стек
изолированно копируется в рекурсивный контекст вложенного документа.

## Consequences
- Константная память на любом объёме строк; нет аллокаций тяжёлых объектов на строку.
- Детерминированные пути: вложенный документ физически не может нарушить баланс токенов
  и структуру путей родительского документа.
- Паттерны 1–2 из docs/patterns/plugin.md зафиксированы как архитектурное решение.
